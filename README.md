# WHY IT Services — Standalone Web Application

This is the dedicated, standalone frontend web application for **WHY IT Services**, developed using React 18, Vite 5, Tailwind CSS, and Lucide Icons.

## Features
- **Standalone Repository Structure:** Built as an isolated project folder (`why-website-it-services`) ready for independent review, development, and deployment.
- **Tenjumps-Inspired Light Theme:** Professional porcelain white (#FAFAFC), deep slate typography (#0F172A), and royal blue (#1E40AF) visual hierarchy.
- **Home Page (8 Sections):** Hero banner, verified trust strip, 4 core service cards, 4 real WHY advantages, featured case study with modal, client testimonials, industries served, and consultation lead intake form.
- **About Us Page (5 Sections):** Intro, 3-stage story (How It Started, What We've Built, Where We're Going), mission/vision/5 core values, leadership team, and verified company numbers.
- **No Inverted Claims:** Zero GCC claims or unverified metrics, following exact brand guidelines.

## Quick Start (Running Standalone)

1. Open a terminal in this directory:
   ```bash
   cd "c:\Users\91915\Desktop\WHY WEB CHANGES\web.2\why-website-it-services"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
